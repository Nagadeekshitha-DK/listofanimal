# listofanimal
link to see my website:https://detailofanimals.ccbp.tech/
This is a simple and responsive Animals Information Webpage built using HTML, CSS, and Bootstrap. The project displays different animals on the home page, and each animal has a “View Details” button that navigates to a separate section with more information and a themed background.

The webpage uses Bootstrap flexbox utilities for layout and the CCBP UI Kit for section navigation.
Features:
Home page displaying multiple animals
“View Details” buttons for each animal
Separate detail sections with background images
Back button to return to the home page
Responsive layout using Bootstrap
